# FeatherStore - iOS App Store & IPA Signer

مشروع تطبيق آيفون كامل بلغة Swift يتيح لك إضافة سورسات (JSON Repositories)، تصفح التطبيقات، تحميل ملفات IPA، توقيعها إلكترونياً وتثبيتها مباشرة على الجهاز.

## 🚀 المميزات (Features)
- 📦 **إدارة السورسات:** إضافة وجلب التطبيقات من روابط JSON خارجية.
- 📥 **تحميل التحديثات والتطبيقات:** إمكانية تحميل ملفات الـ IPA مباشرة.
- ✍️ **محرك التوقيع:** دعم التوقيع بواسطة شهادات `.p12` وملفات التوفير `.mobileprovision`.
- 🌐 **تثبيت مباشر:** تشغيل خادم محلي HTTP لتثبيت التطبيقات الموقعة مباشرة عبر `itms-services`.
- ⚡ **تكامل GitHub Actions:** يبني ملف `.ipa` جاهز للتثبيت تلقائياً عند الدفع (Push) للكود.

## 🛠 البنية الهيكلية للمشروع (Architecture)
```text
FeatherStore/
├── Models/
├── Views/
├── Services/
├── Info.plist
└── FeatherStoreApp.swift
```

## ⚙️ التجميع والتثبيت عبر GitHub Actions
المشروع مجهز بـ Workflow جاهز لـ GitHub Actions. كل ما عليك فعله:
1. ارفع الكود إلى مستودع GitHub خاص بك.
2. انطلق إلى تبويب **Actions**.
3. قم بتحميل ملف الـ `.ipa` من الـ Artifacts بعد انتهاء عملية التجميع (Build).
